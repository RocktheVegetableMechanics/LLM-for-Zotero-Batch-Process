# v3.9.9.1 迁移清单

上游正式标签：[v3.9.9](https://github.com/yilewang/llm-for-zotero/releases/tag/v3.9.9)，提交 4d20b41442c89dfe047fce7d2627928763be558a。

|功能或修复|迁移决策|
|---|---|
|顺序批量、追加去重、拖放/拖动/缩放、暂停/停止/重新排队|迁移到 TypeScript paperBatch.ts / paperBatchRuntime.ts|

|跨重启队列|两版共用 profile/llmforzotero/paper-batch-v1.json 格式；中断项不自动重跑|
|后台归属、独立论文会话和保存回读|迁移并保留会话身份检查；切换前台不撤销后台执行|
|普通聊天保存失败后重试|仍需要，迁移；Agent 模式写入后置标志已由上游处理|
|unparseable actions / skill_binding 旧语义解释恢复|上游已移除该前置解释服务，保留新直接工作流，不重新引入旧机制|
|Delegated action results 显示、脚本完成判定|使用上游连接运行时收据处理及显示过滤；保留真实验证约束|
|Publishing document 刷新|上游已有发布通知订阅，保留，不叠加旧轮询器|
|旧工作流 full-read 来源绑定|按上游读取接口适配，复用当前轮捕获范围，仍要求主机读取证据|
|Codex Responses 断流|移植有界恢复；不执行不完整工具参数；保留已完成输入|
|MCP 300 秒超时|保留 1800 秒工具等待配置及预检缓存签名；不改变工具权限|
|gpt-6-astra|上游能力注册表及动态模型目录已支持，保留|
|长会话刷新、检索、MinerU 分片、统计/日志|保留上游实现|
|回复用户提问后的超时竞争|本轮发现，两版修复|
|Windows 原生 cd 无参数查询|新版修复只读分类，带参数仍走正常审查|
|Windows 命令输出保存与验证|修复原生命令路径转换和重定向包装附加空格；真实文件工作流验证|
|完成后的下一批任务|新增“新建队列”，保留已有论文会话并允许选择新提示词|
|恢复按钮字体缩放|按字体高度调整按钮最小高度，保留完整内边距|
|320px 窗口及 180% 字号下的标题栏重叠|缩小模式标签左右留白，保留图标及文字尺寸|
|PDF 阅读器冷启动|首次页面读取曾在文档就绪前超时，将有界等待从 2.2 秒延长至 10 秒；不更改读取范围|
