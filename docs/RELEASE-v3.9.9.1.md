# v3.9.9.1 — 上游 v3.9.9 + 持久批量分析

基于上游正式 v3.9.9 的完整 TypeScript 工程开发，保留上游长会话渲染、检索流程、MinerU 分片及统计/日志改进。插件 ID、已有会话和配置保持兼容。

- 顺序处理多篇论文：追加去重、内置及自定义提示词同步、独立模型和推理选择、暂停、停止、重新排队、打开对应论文会话。
- 跨重启保存队列。恢复后暂停，未完成的运行项标记“中断待确认”，不会自动重复分析；两版使用相同文件格式。
- 每篇执行前先保存队列状态；保存失败明确提示并暂停推进。完成状态须经会话保存回读确认。
- 完成或停止后可“新建队列”，重新选择提示词；历史会话继续保留。
- 修复回答保存失败后重试、后台任务窗口归属、窗口关闭清理、Codex 提问回复后的超时竞争、输入流恢复和 MCP 工具等待。
- 适配全文来源绑定，仍要求目标论文的主机读取证据。保留上游直接工作流和文档发布订阅，不重新引入旧语义解释前置服务。
- 修复 Windows 命令输出路径和重定向空格，以及恢复按钮在字体放大时的高度、窄窗口大字号下的标题栏按钮重叠。
- PDF 页面读取在阅读器冷启动时最多等待 10 秒，减少文档尚未初始化就报错的情况。
- 主动停止正在执行的请求时明确返回取消状态，避免队列误记为“未完成”。

完整源码在 development/，构建输出在 src/extension/。dist/ 包含新版及修订版 3.9.6.16；旧版源码和回归测试另存于 legacy/3.9.6.16/。

队列操作与恢复说明见 docs/BATCH-QUEUE.md。

验证：两版各用 Luna / Max 和原有自定义分析提示词连续完成两篇真实论文，保留测试会话；新版另验证重启回读、PDF 冷启动读取和 Sol / Low 短任务控制。旧版 13 个回归文件通过，新版完整单元测试 7057 通过、1 pending；最后取消状态修订后 15 项针对性测试、类型检查和构建通过。原生全量工作流仍有侧栏生命周期和响应时间限制，详见 docs/VALIDATION.md，未宣称全部原生测试通过。

请先完成或暂停现有队列，再手动安装本 Release 的 XPI 并重启 Zotero。同版本修订、迁移清单和验证限制分别见 docs/RELEASE-v3.9.6.16.md、docs/MIGRATION-v3.9.9.1.md、docs/VALIDATION.md。

模型服务、网络及外部解析器仍可能失败。本版本保留失败诊断及会话，不将未验证的写入或文档发布标为成功。
