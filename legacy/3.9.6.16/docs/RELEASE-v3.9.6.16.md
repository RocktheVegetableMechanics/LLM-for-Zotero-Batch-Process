# v3.9.6.16 同版本修订（2026-09-21）

此版本覆盖原 v3.9.6.16 的安装包，内部版本号和插件 ID 保持不变。原安装包及提交在本地保留供回退。

- 新增跨重启批量队列：独立原子 JSON 文件保存顺序、文献身份、展开后的提示词、模型/推理配置及会话入口，不保存账号密钥。
- 恢复后保持暂停。运行中断的论文需检查会话并手动重新排队；完成项仍可打开。
- 执行前落盘，保存失败暂停推进并显示错误；损坏队列不被静默清空。
- 新增“新建队列”：当前任务完成或明确停止后，可以重新选择提示词并建立下一批；历史论文会话保留。
- 修复回答保存失败后无法重试，以及同一保存操作并发重复写入的问题。
- 修复 Windows 队列文件路径、插件卸载时队列窗口和监听器清理、独立窗口打开批量入口后的焦点。
- 修复窗口关闭时清理回调提前移除任务中止回调的问题；空的已存在队列文件按损坏文件处理并保留。
- 修复 Codex 提问得到回复后，原等待计时器可能立即触发超时的竞争。
- 保留原有语义解释字段诊断及有限重试、后台任务归属、单篇失败继续、模型配置与会话保存修复。

测试和真实运行记录见最终 VALIDATION.md。模型服务、网络或外部解析器仍可能失败；失败状态及会话会保留，不以普通文本冒充已验证的写入成果。
